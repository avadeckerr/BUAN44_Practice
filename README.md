# BUAN44_Practice
GitKraken Workflow Practice

## Web app (live preview)

A small Next.js app in `web/` that visualizes the same mtcars analysis as `GitPractice.R`.

```bash
cd web
npm install
npm run dev
```

Then open http://localhost:3000. Edit `web/app/page.js` and the page updates as soon as you save.
